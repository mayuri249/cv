# cv

## Emotion detection script

This repository now includes a webcam-based emotion detection example in `emotion_detection.py`.

### Requirements

- Python 3
- OpenCV (`opencv-python`)
- NumPy
- Keras / TensorFlow
- A trained model file named `emotion_model.h5` in the project root

### Run

```bash
python emotion_detection.py
```

Press `q` in the video window to quit.
